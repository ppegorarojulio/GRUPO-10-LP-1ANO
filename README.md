# GRUPO-10-LP-1ANO
Este projeto apresenta-se como uma landing-page do Projeto Conviva, uma plataforma voltada ao público idoso para que possam encontrar atividades recreativas, com o intuito de combater a solidão e isolamento social nesta faixa etária. Possui como objetivo explicar sobre a importância e necessidade da nossa plataforma desenvolvida no Hackathon II do Instituto Federal Catarinense em 2026.

Grupo: 10 (1º ano)
